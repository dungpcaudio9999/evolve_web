Font nội dung **Be Vietnam Pro** nạp qua `next/font/google` (không cần file ở đây). PLAN ghi Poppins nhưng Poppins **không có chữ Việt có dấu**, nên đổi sang Be Vietnam Pro (cùng phong cách hình học, thiết kế cho tiếng Việt).

**Lưu ý:** Panchang **không có chữ tiếng Việt có dấu** (Ư, Ả, Ệ, Ợ…). Chỉ dùng `font-heading` cho logo và tiêu đề tiếng Anh (Issues, Projects…); chữ tiếng Việt sẽ rơi về Be Vietnam Pro và trông lẫn font.
